# ML for Power-System Optimization under Uncertainty: a daily reading curriculum

One 7–10 minute read every day. The reading covers the grid physics, optimal power flow, optimization and
forecasting under uncertainty, and the machine learning used to approximate and safeguard those decisions:
graph and spatio-temporal networks, physics-informed learning, uncertainty quantification and conformal risk
control.

- [`curriculum.md`](curriculum.md): the plan. It has six phases with their focus windows, all lessons with
  their main references, and the weekly rhythm (3 focus lessons + 4 cross-phase entries).
- [`log.md`](log.md): every entry, newest first.
- [`tracks/`](tracks): the same entries, sorted into one folder per track.

Each entry links its main reference (a book chapter, tutorial or the original paper), explains the core ideas,
shows how it connects to earlier entries, and ends with a few self-check questions.
